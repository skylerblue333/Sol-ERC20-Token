# Changelog

## 0.2.0 - Engineering beta

- Align Hardhat compiler with Solidity `^0.8.20`.
- Declare the ethers and chai Hardhat plugins used by the test suite.
- Expand tests for supply, transfers, allowances, `transferFrom`, and insufficient balances.
- Replace compile-only CI with compile, test, and high-severity dependency-audit gates.
- Reclassify the repository as an engineering lab with explicit deployment and security boundaries.
- Add a dedicated security policy.

No blockchain deployment is included in this release.
